# Portfolio

Учебное портфолио студента Тюменского государственного университета по направлению «Компьютерная безопасность».

Здесь собраны лабораторные работы, учебные проекты и практические задания по компьютерным сетям, программированию и системному администрированию, а также сертификаты и дипломы.

## Направления

### [Компьютерные сети](./computer-networks/README.md)

Настройка сетевой инфраструктуры, работа с DNS-серверами, маршрутизация, IP-адресация и диагностика сетевых соединений.

### [Программирование](./programming/README.md)

Учебные программы, решение алгоритмических задач, работа с Python и SQL, изучение принципов объектно-ориентированного программирования.

### [Системное администрирование](./system-administration/README.md)

Работа с Linux и Windows, настройка серверов, виртуальных машин, сетевых интерфейсов и системных служб.

### [Достижения и сертификаты](./achievements/README.md)

Сертификаты, дипломы и другие документы, подтверждающие участие в образовательных мероприятиях и технических соревнованиях.

## Технологии и инструменты

- **Сети:** IPv4, DNS, DHCP, TCP/IP, RIP, OSPF.
- **Операционные системы:** Linux, Ubuntu Server, Windows.
- **Виртуализация:** VirtualBox.
- **Программирование:** Python, C++, SQL.
- **Инструменты:** Git, GitHub, командная строка.

## О проекте

Материалы портфолио основаны на учебных лабораторных работах и практических заданиях. Для каждого проекта указываются задача, использованные технологии, ход выполнения и результаты проверки.
