# Программирование

Раздел содержит учебные программы и практические задания, выполненные в процессе изучения программирования.

## Основные направления

### Python

- Написание программ с нуля.
- Использование функций и классов.
- Основы объектно-ориентированного программирования.
- Работа с файлами и каталогами.
- Обработка исключений.
- Использование сторонних библиотек и виртуальных окружений.

### C++

Изучение основ языка и решение учебных задач.

### SQL и базы данных

- Выполнение запросов `SELECT`.
- Объединение таблиц с помощью `JOIN`.
- Группировка данных и агрегатные функции.
- Создание таблиц и работа с ключами.
- Основы реляционных баз данных.

## Проекты

В этом разделе будут размещаться исходный код, инструкции по запуску и примеры работы программ.

Для каждого проекта планируется указать:
- задачу и требования;
- используемые технологии;
- особенности реализации;
- пример запуска и результат выполнения.

## Инструменты

- Python
- C++
- SQL
- Git и GitHub
- Visual Studio Code
- Терминал и средства запуска программ

## О разделе

Представленные материалы предназначены для демонстрации учебного опыта и освоения основных инструментов разработки. Уровень владения технологиями следует оценивать по конкретным проектам и их реализации.
