# Достижения и сертификаты

В этом разделе собраны сертификаты, дипломы и другие документы, подтверждающие образовательные и технические достижения.

## Сертификаты

Здесь размещаются сертификаты о прохождении курсов, образовательных программ и технических мероприятий.

Для каждого документа указываются:
- название;
- организация;
- год получения;
- ссылка на подтверждение, если доступна.

## Дипломы и награды

Здесь размещаются дипломы за участие и достижения в олимпиадах, конкурсах, соревнованиях и других мероприятиях.

Для каждого документа указываются название мероприятия, год и результат участия, если он предусмотрен.

## Документы

Файлы будут добавляться по мере оформления портфолио.

При публикации документы проверяются на наличие персональных данных и другой конфиденциальной информации.
